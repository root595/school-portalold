# بوابة المدرسة الإلكترونية والسجلات الإدارية

موقع إلكتروني مدرسي متكامل واحترافي باللغة العربية، مبني باستخدام **React + Vite + TypeScript + Tailwind CSS**، مع لوحة تحكم إدارية شاملة وقاعدة بيانات **Supabase** ومصادقة آمنة، جاهز تمامًا للنشر على **Vercel** وإدارة الملفات عبر **GitHub**.

---

## 🌟 مميزات المشروع

1. **واجهة عامة احترافية ومتجاوبة بالكامل (RTL):**
   - **الصفحة الأولى (الرئيسية):** تعرض فقط صورة المدرسة الرئيسية بشكل كبير وواضح ومتجاوب دون أي نصوص أو بطاقات مشتتة.
   - **الصفحة الثانية (السجلات الإدارية):** تعرض المقدمة المعتمدة وشبكة السجلات الإدارية السبعة عشر (17) مع إمكانية فتح مجلدات Google Drive مباشرة في نوافذ جديدة.
   - **الصفحة الثالثة (الرؤية والرسالة):** متوافقة مع الهوية التعليمية ورؤية المملكة 2030 مع عرض القيم المؤسسية.

2. **لوحة تحكم إدارية متكاملة (`/admin`):**
   - **إدارة الصفحة الرئيسية:** تغيير صورة المدرسة، الرفع المباشر إلى Supabase Storage، معاينة فورية، تعديل النص البديل، أو استبدالها وحذفها.
   - **إدارة السجلات:** إضافة سجلات جديدة، تعديل الاسم والوصف ورابط Google Drive والأيقونة، التحقق من صحة الروابط، حذف مؤكد بنوافذ تأكيد، وإعادة ترتيب السجلات بالسحب أو الأسهم وإخفاء/إظهار أي سجل.
   - **إدارة محتوى الصفحات:** تعديل اسم المدرسة، مقدمة السجلات، نصوص الرؤية والرسالة، وعناوين وظهور صفحات القائمة.
   - **تخصيص التصميم:** لوحة ألوان تفاعلية لاختيار اللون الأساسي والثانوي وخلفية الموقع، انحناء زوايا البطاقات (Border Radius)، مقاس الخطوط، إخفاء/إظهار الأيقونات، واستعادة التصميم الافتراضي بنقرة زر.
   - **إعدادات الموقع والتواصل:** تعديل عنوان الموقع ووصف الـ SEO، أرقام الهواتف، البريد، واتساب، وحساب منصة إكس.

3. **أمان وقاعدة بيانات حقيقية (Supabase & RLS):**
   - تسجيل دخول آمن للمدير عبر Supabase Auth.
   - حماية كاملة على مستوى الصفوف (Row Level Security): الزوار يستطيعون قراءة السجلات المنشورة فقط، ولا يستطيع أحد التعديل أو الحذف إلا المدير المعتمد.
   - مخزن سحابي مخصص للصور (Supabase Storage: `school-assets`).
   - وضع محاكاة محلي (Local Mode) للاختبار المباشر قبل الربط بالسحابة دون توقف الموقع.

```text
│   ├── types/              # تعريفات TypeScript
│   ├── App.tsx             # التوجيه وعرض الصفحات
│   ├── index.css           # أنماط Tailwind ومتغيرات الألوان
│   └── main.tsx            # نقطة انطلاق التطبيق
├── supabase_schema.sql     # مخطط قاعدة البيانات وسياسات RLS الكاملة
├── .env.example            # نموذج متغيرات البيئة
└── README.md               # دليل التشغيل والنشر
```

## 🗄️ إعداد Supabase خطوة بخطوة

1. أنشئ حسابًا جديدًا في [Supabase](https://supabase.com) واضغط **New Project**.
2. اختر اسمًا للمشروع وكلمة مرور قوية لقاعدة البيانات والمنطقة الأقرب لك.
3. بعد اكتمال إنشاء المشروع، توجه إلى قائمة **SQL Editor**.
4. افتح الملف `supabase_schema.sql` من مشروعنا أو انسخه مباشرة من قسم «قاعدة البيانات والنشر» داخل لوحة التحكم.
5. الصق الكود واضغط **Run** (سيقوم تلقائيًا بإنشاء الجداول، سياسات RLS، مخزن الصور `school-assets`، وإدراج السجلات الـ 17 الأولية).
6. لإنشاء حساب المدير الأول بأمان:
   - توجه إلى قائمة **Authentication** -> **Users**.
   - اضغط **Add user** ثم **Create user**.
   - أدخل بريدك الإلكتروني (مثل: `admin@school.edu.sa`) وكلمة المرور.
   - فعّل خيار **Auto Confirm User** واضغط حفظ.
7. احصل على بيانات الاتصال من: **Project Settings** -> **API**:
   - `Project URL`
   - `anon public key`

## 🌐 النشر على Vercel وربط GitHub

1. ارفع المشروع إلى مستودعك على **GitHub**:
   ```bash
   git init
   git add .
   git commit -m "الموقع المدرسي ولوحة التحكم"
   git branch -M main
   git remote add origin https://github.com/USERNAME/school-portal.git
   git push -u origin main
   ```
2. سجل الدخول إلى [Vercel](https://vercel.com) واضغط **Add New Project**.
3. اختر مستودع الـ GitHub واضغط **Import**.
4. في صفحة الإعدادات، افتح تبويب **Environment Variables** وأضف:
   - `VITE_SUPABASE_URL` = رابط مشروع Supabase الخاص بك
   - `VITE_SUPABASE_ANON_KEY` = المفتاح العام Anon Key
5. اضغط **Deploy**. سيبدأ البناء وينتهي خلال ثوانٍ معدودة.

## 🔒 الأمان وسياسات الحماية (RLS)

- تم تفعيل **Row Level Security (RLS)** لضمان أقصى درجات الأمان.
- لا يمكن لأي زائر التعديل على أي سجل أو إعداد أو رفع ملفات دون تسجيل دخول رسمي عبر `Supabase Auth`.
- عند تسجيل الخروج، يتم إنهاء الجلسة فورًا ولا يمكن الوصول لصفحات الإدارة إلا ببيانات صالحة.
